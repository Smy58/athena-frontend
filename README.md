# Athena Frontend

Vue 3 + Vite фронтенд для клуба **Афина**. Работает поверх `athena-backend`
(NestJS + Prisma) — API-слой уже целиком настроен под его эндпоинты.

## Стек

- **Vue 3** (`<script setup>`) + **Vite**
- **Vue Router** — с гардом `requiresAuth`
- **Pinia** — стор авторизации (JWT в localStorage)
- **Axios** — с интерцептором, автоматически подставляющим токен

## Установка

```bash
npm install
cp .env.example .env
# укажи адрес своего бэкенда, по умолчанию http://localhost:3000/api
npm run dev
```

Открой `http://localhost:5173`. Бэкенд (`athena-backend`) должен быть запущен параллельно.

## Что уже полностью работает

- Регистрация / вход (реальные запросы к `/auth/register`, `/auth/login`)
- Хранение JWT и профиля в Pinia + localStorage
- Защищённые маршруты (кабинет, персонажи — редиректят на `/login`, если не авторизован)
- **Персонажи** — полный CRUD: список, создание, лист персонажа с рабочим трекером ХП
  (урон/лечение реально уходят в `PATCH /characters/:id`), удаление

## Честно о том, чего пока нет

Бэкенд уже умеет больше, чем показывает интерфейс — эндпоинты для Доски заданий,
Гильдий, Магазина и Поддержки готовы (`src/api/quests.js`, `guild.js`, `shop.js`,
`support.js` уже написаны и ждут своих экранов), просто под них ещё нет Vue-страниц.

Не перенесено из старого HTML-прототипа (`athena-dnd-club-2024.html` — держи его
рядом как референс по вёрстке и логике, когда будешь переносить):

- Полная генерация персонажа по правилам D&D 2024 (виды, бонусы предыстории,
  автоподбор ячеек заклинаний, спасброски, навыки, инвентарь, заметки, история бросков)
- Доска заданий, Гильдии, Магазин (звания/зелья/пойки), Расписание игр, Мастера
- История, FAQ, Поддержка (чат), отзывы
- Мобильное меню, кубики/бросок, анимации

## Как продолжать

Открой эту папку в **Claude Code** рядом с `athena-backend` и `athena-dnd-club-2024.html`
и проси переносить раздел за разделом — например:
«перенеси Доску заданий из HTML-прототипа в Vue-компонент, используя `src/api/quests.js`».
Структура (api / stores / views) уже задаёт паттерн, дальше это в основном копирование
логики и вёрстки по разделам.
